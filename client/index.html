How this maps to x402

  1. Client requests protected resource
  2. Server returns HTTP 402 + accepts[] PaymentRequirements
  3. Client settles exact amount on Hedera (HBAR or USDC) to server payTo
  4. Server verifies (mirror and/or facilitator) and returns the PDF
